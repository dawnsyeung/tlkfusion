# White Eagle Nutrition × TLK Fusion

Retail product overview for placing **White Eagle Nutrition** whole dried black soldier fly larvae (5 lb, 10 lb, 20 lb) with farm, feed, poultry, and specialty retailers.

## Live site

**Site:** [tlkfusion.earlylight.io](https://tlkfusion.earlylight.io)

Open locally by opening [`index.html`](index.html) in a browser.

The public page is an informational product brief for TLK Fusion brokers:

- What the product is and who buys it
- Why retailers stock it
- SKU roles (5 / 10 / 20 lb)
- Benefits and BSFL vs mealworms
- Talking points, common questions, shelf/online story, and sell sheet

Incomplete operational fields and internal process templates live on a **hidden** page (`/internal`) that is not linked from the public nav and is marked `noindex`.

## Source document

- [`TLK_Fusion_Retail_Outreach_Master.md`](TLK_Fusion_Retail_Outreach_Master.md) — longer working source document (markdown)

## Deploy

Static site configured for Vercel via `vercel.json`. Production domain should point at this repo’s production branch (`main`) so the root `index.html` is served at `/`.
